# H1-01 paper deck — DO NOT READ BEFORE PLAYING

Spoilers for the H1-01 self-test. Rules and hidden outcomes below; the agent deals in chat.

## Rules

- Four meters, 0–10, all start at 5: WATER, AIR, TEMP, MOOD. Values clamp at 10.
- Any meter at 0 = death (WATER: dehydration · AIR: suffocation · TEMP: exposure · MOOD: the human
  gives up). Score = days survived (1 cycle = 1 day, max 10).
- Each day: one alien question (symbols + shaky translation) and 2–3 alien-proposed answers. Only
  captions are shown; effects are hidden until chosen. Outcomes are deterministic (per §3).
